# Guía visual — Clase 28 (Agentes)

## Antes de la clase
- [ ] Cuenta Claude o ChatGPT (mejor si tienes Plus/Pro).
- [ ] System prompt de la Clase 25 a mano.
- [ ] Datos del proyecto listos para subir.
- [ ] Adobe Illustrator instalado con Creative Cloud activo (para el ejercicio de MCP).

## Claude Projects (más simple)
1. [claude.ai](https://claude.ai) → sidebar → Projects → New.
2. Custom instructions: pega el system prompt.
3. Knowledge: subir 2-3 archivos.
4. Empezar a chatear.

## Claude Skills (si tu plan las incluye)
1. En el chat, ícono de tools/skills.
2. Activar las que necesitas: Web Search, Computer Use, etc.
3. Pedile algo que requiera acción externa.

## Custom GPT (ChatGPT Plus)
1. Sidebar → Explore GPTs → Create.
2. Configure name + instructions.
3. Activar capabilities: Browsing, DALL·E, Code Interpreter.
4. Save.

## MCP de Adobe Illustrator (agente + herramienta real)
1. Claude Desktop → *Settings* → *Connectors* → agregar **Adobe for Creativity / Illustrator MCP**.
2. Autorizar con tu cuenta de Adobe (Creative Cloud).
3. Abrir `Illustrator_mcp.ai` (misma carpeta) en Illustrator y dejarlo abierto.
4. Pedirle al agente que revise o modifique algo del archivo (ver Ejercicio 5 de la clase).
5. Capturar screenshot del antes/después.

## Regla de oro
> Para acciones con consecuencias externas (email, compra, publicar) → **siempre pedir aprobación humana**.

## Subir al repo
- `docs/arquitectura_agente.md` completado.
- Screenshots del agente funcionando (incluye antes/después de `Illustrator_mcp.ai`).
